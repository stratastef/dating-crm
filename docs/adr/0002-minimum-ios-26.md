# Minimum iOS version is 26

The redesign raises the deployment target from iOS 18.0 to iOS 26, so the app can use the iOS 26 tab bar (a bottom accessory strip that shows when autopilot is paused, minimizing on scroll) and glass effects on custom controls. TestFlight testers on iOS 25 or older can no longer install the app; the beta is small and the owner's phone runs iOS 26 or later.
