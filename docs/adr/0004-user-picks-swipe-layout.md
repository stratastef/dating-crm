# The user picks the Swipe layout during onboarding

Swipe has two layouts, and onboarding asks the user which one they want: one swipe candidate at a time (large photos, the AI's suggestion on a labeled line, Pass and Like buttons, no drag gesture) or a scrolling list with the suggestion preselected on each row and "Accept all suggestions". The owner chose this over picking one layout, because careful review and fast batch triage suit different users. Both layouts are kept and the choice can be changed later; do not remove one to simplify the screen.
