# Product name: Goodhour

The product needed a real name before the public web app and the first TestFlight build. The owner chose **Goodhour**, after the one number the app optimizes: good dates per hour of your time. The brand kit is in `docs/brand/`.

On 2026-11-25 no US App Store app used the name and no brand turned up in a web search. `goodhour.ai`, `goodhourapp.com`, `trygoodhour.com` and `goodhour.dating` were unregistered; `goodhour.com` was registered without a site and `goodhour.app` was taken. No trademark search has been done yet; it comes before buying the domain.

The iOS bundle ID changes with the name, so the rename lands before the first TestFlight upload; App Store Connect fixes the bundle ID after that.

## Considered options

- **Swain**, **Courtly**, **Billet Doux**, **Second Date**, **Gallant**: free of dating-app collisions but weaker: gendered, crowded by basketball apps, hard to spell, too generic to trademark, or no domain.
- **Aside**, **Blackbook**, **Cyrano**, **Datebook**, **Suitor**, **Datum**, **Rendez**: each is already a dating or dating-journal app on the App Store.
- **Matchbook** and any name with "match": Match Group enforced its "match" mark against muzmatch, which lost in the UK in 2023 and rebranded as Muzz. The product already carries Match Group risk; the name should not add to it.
- **Overture**: one letter from Overtone, the Hinge founder's AI dating app.
